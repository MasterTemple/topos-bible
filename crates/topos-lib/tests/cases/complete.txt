# Completion cases: `input => the first completions, in order`, separated by ` | `. The input
# ends at the cursor; each completion is its label (the reference as it would be written).
# - `[join]` before the input joins adjacent verses; `[abbreviation]` abbreviates books
# - Nothing after `=>` means no completions
# - Every front end runs these: the library (tests/complete.rs), the CLI (--complete), the
#   bindings (topos-ffi), the language server, and the Obsidian plugin, so they can't drift apart
